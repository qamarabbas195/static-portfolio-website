# Project 1: Static Portfolio Webpage

This is my submission for **DecodeLabs Frontend Development – Project 1: Static Webpage Design**.

## About
A simple static personal portfolio website built using **HTML5** and **CSS3**. The goal of this project was to practice semantic HTML structure and clean CSS styling. This version is packaged as a single self-contained HTML file, all CSS and images are embedded directly inside `index.html`, so no separate folders are needed to run it.

## Features
- Semantic HTML tags (`header`, `nav`, `main`, `section`, `article`, `footer`)
- One `h1` per page with a proper heading hierarchy
- Hero section with an introduction and call-to-action button
- About section with profile image and description
- Skills section displayed as styled tags
- Projects section using a responsive CSS grid
- Contact form (front-end only, no backend)
- Basic responsive design using a media query for smaller screens
- CSS embedded in a `<style>` tag and images embedded as base64, everything runs from one file

1. Download `index.html`.
2. Open it directly in any web browser, double click works.
3. No build tools, installations, or extra folders are required.
